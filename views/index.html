Sobre mí

Soy un desarrollador Full Stack con experiencia construyendo aplicaciones web para entornos exigentes. He trabajado en el desarrollo de sistemas institucionales para el Gobierno de la Ciudad de México, donde aprendí a priorizar la seguridad, la escalabilidad y la calidad del código.

Mi stack principal gira en torno a Node.js + Express en el backend con MySQL como base de datos, combinando patrones de arquitectura MVC para mantener el código organizado y mantenible. En el frontend trabajo con HTML, CSS y JavaScript vanilla o Bootstrap según el proyecto.

Me enfoco en construir soluciones que resuelvan problemas reales: sistemas de autenticación seguros, APIs robustas y plataformas que escalen. Estoy disponible para proyectos freelance y colaboraciones remotas.
